# TrackTour

## Project

TrackTour is a tourism promotion and food-delivery web application
for Bansud, Oriental Mindoro.

## Purpose

The system combines:

- Tourism promotion
- Tourist destinations
- Tourism businesses
- Hotels and resorts
- Restaurants and food hubs
- Food delivery
- Rider delivery services
- Online payments
- Rider GPS tracking
- Tourism Office administration

## Technology

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Laravel
- REST API
- Laravel Sanctum
- RBAC

### Database
- MySQL

### Payments
- PayMongo
- GCash
- COD

### Maps
- Leaflet

### Realtime
- Node.js
- Socket.IO
- WebSockets
